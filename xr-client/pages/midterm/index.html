Where do I get a token?

Easiest, with the GitHub CLI: run gh auth token in a terminal and paste the output.

Or create a classic token with the repo scope (fine-grained tokens cannot read a repository of another user): github.com/settings/tokens/new.

The token is only sent to api.github.com to read the deck key, and is not stored. The key stays in this tab until you close it.
