• Moved from web to Unity • Frame rate: 34 → 72 fps. Chrome copied every frame • Delay: 141 ms. Measured with a flashing screen • Was 302 ms: video waited for unused audio. Removed it • Reprojection: frame shown where robot looked. Head turns feel instant • Panorama fills the edges • Shake: head pose arrives unevenly. Now use commanded pose, 5× less shake • Head play: 3° command barely moves it. Found with photos, app accounts for it • Open: speaker following turned too far. Removed until we know why
